# PRD (초안)

기준: Obsidian 문서 `가족용 기프티콘 바코드 모음 앱 기획서`

## 제품 방향
- 플랫폼: 외부 배포형 웹 앱(PWA) 우선
- 지원: iPhone Safari + Android Chrome 동시 지원
- 계정: Google OAuth 로그인 필수

## 제품 원칙 (우선순위)
- 1순위: 만료 임박 쿠폰을 먼저 쓰게 돕는다.
- 2순위: 가족이 같은 정보를 보고 중복 사용/누락을 줄인다.
- 3순위: 등록은 빠르게, 확인은 더 빠르게.

## 문제 정의
- 가족 구성원마다 기프티콘이 메시지/앨범에 흩어져 관리가 어렵다.
- 만료일을 놓쳐 소멸되는 쿠폰이 자주 발생한다.
- 가족 간 공유/사용 상태 업데이트가 번거롭다.

## 핵심 범위 (MVP)
1. Google OAuth 로그인
2. 가족 그룹 생성/초대/참여
3. 수동 등록 + 이미지 업로드
4. 바코드/쿠폰번호 표시
5. 만료일 기반 정렬/임박 상태 표시 (임박 우선 홈 카드)
6. 사용 완료 처리 + 히스토리

## 주요 화면 (초안)
- 홈: `오늘 만료`, `D-3`, `D-7` 임박 구간을 최상단에 노출
- 쿠폰함: 전체 목록 + 상태 필터(사용 가능/사용 완료/만료)
- 캘린더: 날짜별 만료 예정 기프티콘 확인 (월간 뷰)

## 비기능 요구사항
- 모바일 우선 UI (세로 화면 기준)
- 페이지 첫 로딩 3초 이내(일반 LTE 환경)
- 업로드 이미지 보관 및 접근 제어(가족 그룹 단위)

## 배포/운영 (초안)
- 프론트엔드: Next.js (PWA)
- 백엔드: Supabase (Auth, Postgres, Storage)
- 배포: Vercel (외부 접속 URL 제공)
